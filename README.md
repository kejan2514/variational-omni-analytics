# Variational Omni Analytics

A lightweight analytics dashboard for Variational Omni markets.

## Status

Initial project scaffold. This project is designed around Variational's read-only/public market data first; trading functionality will only be added when an official trading API is available and documented.

## Planned dashboard

- Market overview
- Volume and open-interest metrics
- Funding-rate monitoring
- Bid/ask market snapshots
- Search and market filtering

## Safety

This repository does not automate trading or request wallet private keys. Never commit API keys, seed phrases, or private keys to this repository.

## Disclaimer

Community-built project; not an official Variational product.
